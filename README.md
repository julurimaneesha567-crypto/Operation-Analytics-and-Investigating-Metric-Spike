### Operation-Analytics-and-Investigating-Metric-Spike
This project focuses on Operation Analytics and Metric Spike Investigation, acting as a lead Data Analyst to derive actionable business insights using MySQL (v8.0.34) and Microsoft Excel.
### Core Highlights
 Case Study 1 (Job Data Analysis): Analyzes operational throughput, 7-day rolling averages, language distribution (with Persian leading at 37.50%), and duplicate records.
 Case Study 2 (Investigating Metric Spike): Deep-dives into user behavior to analyze weekly active user engagement (peaking in week 30), user growth, device preferences (led by MacBook Pro), cohort retention, and email open rates (~31.19%).
